# Security

Do not put cookies, tokens, account identifiers, or private logs in public issues.
For a suspected vulnerability, use this repository's GitHub **Security → Report
a vulnerability** feature when enabled. If unavailable, open a minimal issue
asking for a private reporting channel without disclosing the exploit or secrets.

The app processes remote metadata and invokes a bundled converter. Keep pinned
dependencies updated and review native build/test results before release.
