# 兼容性与故障排查

[English](COMPATIBILITY.md) | 简体中文

## 验证范围

工作流分别在 Windows Server 2022 x64、macOS 15 Apple Silicon 和 macOS 15 Intel 上执行测试。Windows Server CI 可提供桌面兼容性的依据，但不能代替真实 Windows 11 桌面的交互测试；目标桌面系统为 Windows 11 x64。

每个平台还会原生打包并运行发行版可执行文件，检查界面、MP3 / M4A 转换和打包后的子进程协议。测试使用合成媒体和模拟网络，不验证某个真实账号的收藏夹权限。

应用随包提供 Noto Sans SC 中英文字体，打包检查会验证所需字形。Windows CI 使用原生 Windows Qt 平台插件渲染，避免无系统字体的离屏后端产生方框文字。

无法保证所有电脑和 B 站未来的接口行为。原生检查通过后才发行，并在发行说明中注明未完成的手工检查。Windows 使用关闭时终止的 Job Object 管理下载进程及 FFmpeg 子进程；macOS 使用进程组。

## 常见问题

| 问题 | 检查方法 |
| --- | --- |
| Windows 无法启动 | 完整解压到可写的本地目录；保留 EXE 旁的 `_internal`；确认是 Intel / AMD 64 位系统。核实发行者提示，不要关闭系统防护。 |
| Mac 无法启动 | 选择正确的 Intel 或 Apple Silicon 包；当前目标为 macOS 15 及以上。应用未经公证，请查看“隐私与安全性”中系统给出的说明。 |
| 浏览器 Cookie 无法读取 | 关闭浏览器后重试，或使用自己账号导出的 Netscape 格式 Cookie 文件。加密或企业策略可能限制直接读取。 |
| 无法读取收藏夹 | 使用含 `fid=` 的具体收藏夹链接，检查网络；私有内容需相应登录权限。 |
| 部分条目失败 | 视频可能已删除、无权限或受地区限制。先解决错误原因，再重试。 |
| Windows 路径过长或无写入权限 | 选择短且可写的目录，例如个人“音乐”目录下的文件夹。过深目录或旧文件系统限制仍可能导致失败。 |
| Music 导入失败 | 仅 macOS：允许对 Music 的自动化控制后重试。已下载文件会保留。Windows 无自动导入。 |
| 网站改版后失效 | 更新锁定的 yt-dlp 版本，重新执行各平台测试并打包。 |

## Windows 11 桌面验收

在称某个发行版“已通过 Windows 11 测试”前，应在真实 Windows 11 x64 桌面解压并打开应用；预览有权访问的公开收藏夹；向含空格和中文的路径保存 MP3 和 M4A；停止正在转换的任务；重试失败条目；重启应用；打开保存目录。浏览器 Cookie 访问需单独测试，因为它依赖具体浏览器。
